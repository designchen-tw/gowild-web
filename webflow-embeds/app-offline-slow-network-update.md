# 離線／慢速連線更新 — 2026.11.02.1

## 要更新的兩個位置

1. Cloudflare **原本的離線 Worker**：完整貼入根目錄 `pwa-offline-worker.js` 並部署。保持原 Route `gowild.one/gw-offline/*`，不變更氣象或404地區限制 Worker。
2. Webflow Site settings → Custom code → Footer：完整替換原 GO WILD App Footer 區塊為 `app-footer.html`，保留其他網站程式，再 Publish。

Worker 內建資產版本 `33659d1a6a8ec3f6c9007ed042faaee478b8ecd2`。若 Cloudflare 已設定 `OFFLINE_ASSET_COMMIT`，請更新為此值或移除該變數以使用內建值；舊環境變數會蓋過新版本。Head、四個岩場 Embed、menu overlay、DNS 和 Route 不需重新設定。

既有使用者連線後，在「離線資料」點「檢查內容更新」，出現「App 有新版 · 更新並重新載入」後套用即可。不需要移除 App，也不需要重新下載所有岩場。尚未更新到新版 Service Worker 的裝置仍使用舊載入策略。

## 載入方式

- 已完整儲存的首頁與四個岩場：立即顯示儲存的 HTML，圖片、地圖、字型與版面檔案使用原包內的精確版本網址。
- 開啟／恢復頁面時背景檢查目前岩場 HTML；同一岩場五分鐘內共用結果，不設持續輪詢、不自動下載整包或所有岩場。
- 背景有新內容時只提示「有新版可閱讀」及重新載入，原離線包保持不變。使用者可在閱讀新版後到離線資料更新副本。
- 明確重新整理（瀏覽器重新整理、App工具列、提示中的重新載入）優先讀網路；有備份時最多等待3.5秒，逾時仍可閱讀儲存版本。無備份頁面最多等待8秒，再顯示離線入口。
- 背景頁面／天氣檢查最多等待5秒；期限涵蓋完整回應內容，避免只收到 headers 後一直卡住。
- 天氣有備份時立即顯示上次資料，標示原回應的 fetchedAt，並背景取得新資料。尚未顯示的新資料不清掉舊資料警示；取得不同資料後提示重新載入查看。未有天氣備份時仍需連線。
- 依最後取得時間起算，24小時內保留上次氣象資料並標示時間；超過24小時才標示「資料已過期，正在嘗試更新」。觀測數值與現況色彩停止顯示。潮汐及天氣預報另外依原資料涵蓋時段判斷，仍有效的預報可繼續離線閱讀；地圖、路線、介紹不設此期限。
- 不將「正在顯示儲存副本」直接當成裝置離線；避免有網路時誤擋表單和外部連結。裝置明確斷線時維持原本媒體需連線提示。
- 網路恢復不會突然重整閱讀畫面或填寫中的表單。

## 保留及相容性

- 保持原 `gw-offline-v1-*` 資料命名與格式，舊版離線包繼續可讀。
- 新 Worker 安裝時先保存約數十 KB 的 App／離線介面程式，再等待使用者套用；不自動 skipWaiting。
- 舊儲存 HTML 中的 App/離線載入入口會對應新版小型介面；原岩場內容、地圖和路線程式不混換版本。
- 更新岩場包前先載入新版頁面，避免新 HTML 與舊畫面程式混存；重新載入失敗時提示錯誤，不進入反覆重整。
- 即時影像、YouTube、Windy、PDF、外部網站及表單送出仍需要網路，不列入離線包。
- GitHub 更新不代表 Cloudflare／Webflow 已發布。
