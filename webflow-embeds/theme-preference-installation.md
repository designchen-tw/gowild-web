# 預設跟隨裝置主題

完整替換首頁 `home.html` 及全站共用 `menu-overlay-full.html`，再於 Webflow Publish。其他頁面透過選單提供的 `GWColorTheme` 取得相同選擇，不需重新貼內容 Embed；首頁 Page Code、表單及 Worker 不變。

- 沒有手動偏好時，使用 `prefers-color-scheme: light` 判斷裝置主題，裝置切換時同步；不把裝置預設存成手動偏好。
- 使用者點月亮／太陽後，沿用既有 `gw-color-theme-v1` 儲存鍵，跨頁、重新開啟與同站分頁共用。手動選擇沒有自動到期；舊版已存的手動選擇也保留。
- 點選與當前裝置一樣的主題，仍會記錄為明確手動選擇；重複選取同一手動偏好不重複寫入。
- 清除該儲存鍵或網站資料後恢復跟隨裝置；儲存不可用時仍可依裝置及本頁手動切換。不同裝置、瀏覽器與無痕環境各自處理。
- 維持兩個月亮／太陽按鈕，不新增文字或第三個控制項。重複載入首頁與選單只建立一套監聽；bfcache 恢復時重新確認偏好。原有選單目前頁面綠色、Safari 補色、原生表單及語言切換保留。
