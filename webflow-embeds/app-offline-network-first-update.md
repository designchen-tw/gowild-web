# 網路優先與離線提示修正 — 2026.11.02.2

## 發布步驟

1. Cloudflare **離線 Worker** 貼入根目錄 `pwa-offline-worker.js` 並部署。Route 維持 `gowild.one/gw-offline/*`。
2. Webflow 全站 Footer 的 GO WILD App 區塊完整替換為 `app-footer.html`，保留其他程式，然後 Publish。
3. 若有 `OFFLINE_ASSET_COMMIT`，改為 `2a9c13a9e4434cd227669a40d3425aeeb0148666`，或移除變數以使用 Worker 內建版本。
4. 既有 App 在「離線資料」檢查 App 更新並套用，再重新整理。不需要移除 App、清除資料或重抓所有岩場。

Head、地區限制 Worker、氣象 Worker 不需變更。四個岩場 Embed 的維護版本也已同步新氣象程式；新版 Service Worker 會更新自己控制範圍內的舊頁面載入入口，因此這次不必先重貼四頁 Embed 才能修正既有 App。

GitHub 更新不代表 Cloudflare 與 Webflow 已發布。

## 提示規則

| 狀態 | 顯示 | 提示／消失方式 |
|---|---|---|
| 正常連線，3秒內取得網路頁面與 API | 網路資料 | 沒有額外提示，沿用原更新時間 |
| 整頁超過3秒且有已儲存副本 | 儲存頁面；原網路請求繼續 | 「因為網路較慢，此頁暫用已儲存版本 · 儲存於〔實際時間〕 · 重新整理」；重新整理取得網路頁面後消失 |
| API超過3秒，備份未滿24小時 | 備份數值，原 API 請求繼續 | 「暫用上次氣象資料 · 日期時間 · 正在更新」；成功後自動換新資料並消失 |
| API超時且備份超過24小時 | 觀測／現況標成過期；仍有效的預報保留 | 「氣象資料已過期，正在嘗試更新」；成功後自動恢復數值並移除提示 |
| 裝置完全離線 | 儲存頁面與已儲存資料 | 頁面顯示「因為沒有網路，此頁暫用已儲存版本 · 儲存於〔實際時間〕」，氣象使用「離線資料」；過期時為「氣象資料已過期，等待網路連線」 |
| API最後仍失敗／達25秒上限 | 保留備份或過期狀態 | 顯示暫時無法更新，可重新整理；回到前景或恢復連線時可重試，不假裝一直載入 |
| 整頁沒有備份且連線慢／失敗 | 等候最多約8秒後顯示重新連線入口 | 首次造訪且離線功能尚未接管時，仍由瀏覽器控制整頁載入時間 |
| 沒有備份且 API 失敗 | 原小工具的資料暫缺狀態 | 不顯示「資料已過期」 |
| 主動開啟選單的離線資料檢查內容更新 | 儲存副本與最新內容的比對結果 | 更新提示只在離線資料視窗，首頁不常駐「有新版可閱讀」 |

頁面版本和氣象資料分開：氣象在同一頁自動更新；已使用儲存版本開啟的整份頁面不會自動重整，避免重置地圖／閱讀位置或表單。頁面上方提示需等重新整理取得網路頁面才消失。

## 字型與對齊

- 必要提示沿用所在頁面的真正字型，使用現有細節文字規格：桌機12px、手機10px（有共用字級變數時優先採用）。
- 「重新整理」文字、字重、行高、字距與提示一致，對齊同一文字基準線，移除原本額外的上下 padding／margin。
- 首頁提示左右跟岩場圖卡共用 gutter；岩場頁與該頁內容寬度／左右空白一致。
- 正常連線時不建立多餘的頁面提示，不在攀登現況與氣象卡重複顯示資料來源框。

## 技術範圍與驗證

- `offline-sw-v3.js`：網路優先，3秒才回退；回退不取消原請求，完整回應上限25秒。版面與圖片繼續使用原精確版本的資產快取。
- `offline-v3.js`：只呈現實際使用備份的提示，網路恢復透過事件更新小工具並移除氣象提示。
- 四個條件／預報程式接受背景的新資料，略過晚到的舊回應，避免新數值被離線值蓋回。
- 內容雜湊版本3只排除受管理的 App／離線／提示程式載入標籤；主文、Menu、路線與地圖變更仍會被檢出。舊雜湊由原保存 HTML 重新計算，不用重新下載。
- 安裝時預存離線介面、App 與四個氣象小工具程式，供舊副本在新版 Worker 下繼續使用。
- 測試包含：網路優先、25小時舊備份不影響正常網路、超時回退不取消請求、背景資料自動更新、提示自動移除、離線狀態、中英切換、內容比對遷移與四個小工具避免倒退更新。
- 實際首頁手機版量測：提示與圖卡左緣同為19.5px，提示／重新整理文字均10px、行高16px、相同字型。
- 以實際龍洞版面與測試資料核對：API成功後相對濕度更新為60%、風速更新且提示消失；此為本地測試值，非現場資訊。

既有已下載資料保留，地圖／岩區介紹／路線不設24小時到期。即時影像、Windy、PDF、表單仍需網路。
